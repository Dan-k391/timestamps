Import your KeyStats history, choose a time zone, and count keys that were being missed.

### Install

**Windows:** from 1.1.0, use Settings → About → **Update**, or run the setup. Your data is kept either way. The setup isn't code-signed, so SmartScreen may show "Windows protected your PC": click **More info** → **Run anyway**.

**macOS:** unzip, drag **Timestamps** into *Applications* and open it from there. It isn't notarized by Apple, so the first start is blocked: open it once, then *System Settings → Privacy & Security* → **Open Anyway** (on macOS 14 and earlier, Control-click the app → *Open*). The macOS version hasn't been tested on many Macs yet, so please report what doesn't work.

### What's new

- **Import from KeyStats** (Settings → Data): daily totals, keys and applications from [KeyStats](https://github.com/debugtheworldbot/keyStats) for Windows.
  - The file is found on its own if KeyStats is on this computer. An export from KeyStats works too.
  - Only days before Timestamps started counting are imported, so nothing is counted twice. Importing again replaces those days.
  - KeyStats has no time of day, so imported days have no chart by hour. Shortcuts count for their key (Ctrl+V for V).
  - Files from KeyStats for Mac can't be imported yet.
- **Time zone** (Settings → General): choose one instead of the system's. Clock times, where each day starts, statistics, the tray ring and tags all follow it.
  - Changing it divides your history at the new midnight, so activity can move to a neighbouring date. Key, click and application counts stay on their dates.
  - Screenshot folders keep the system's time.
  - A few zones whose rules changed after 2022, such as Asia/Almaty and Africa/Cairo, may be an hour off.
- **Keys and clicks per application** in Statistics, on every row of Applications and updating as you type.
- **Keys that were missed are now counted:** the Tab of Alt+Tab, and any key an app takes as a global shortcut.
- **Mouse distance in games:** motion now counts when a game holds the cursor still.

### Fixed

- **Tags:** changing the end of a tag that ends at midnight no longer stretches it over the next day and removes the tags there. Saving a tag unchanged in the repeated hour of a clock change works, and a cleared time keeps the old one.
- **Input around Pause, Mark as off, Resume and quitting** is no longer lost, nor when a save fails because the disk is full.
- **Clock changes:** days are right in zones where clocks change at midnight, such as Havana and Beirut. Statistics' start and end times and the "When you work" chart are right on those days, and the overview strip of the day view shows true times and follows the 12-hour clock.
- **Moving Statistics blocks** while the page updates no longer loses a block from the saved layout.
